# 个人日记手帐系统

这是一个基于 Obsidian 的个人日记、家务、财务、计划与复盘系统模板。它不是单纯的日记本，而是把每日记录、待办推进、消费记录、旅行复盘、阶段计划和 AI 辅助整理放在同一套可持续维护的结构里。

这个公开版本只保留方法、结构、模板和脱敏示例，不包含真实日记正文、家庭信息、地点、账号、附件或自动化密钥。

## 适合谁

- 想把日记写成可复盘系统，而不是零散流水账的人
- 需要同时管理生活、家庭事务、旅行、采购、工作记录和长期计划的人
- 已经在用 Obsidian，希望让每日笔记和待办系统连接起来的人
- 想让 AI 帮忙整理每日摘要，但又希望人工记录和 AI 观察分开的用户
- 想把占卜、直觉和第二天复盘放进日记系统的人
- 对制定年度目标和拆解任务感到头疼，希望先获得方向、再落到行动的人

## 核心设计

每日页分为两层：

- 主记录区：今天发生了什么、花了什么、想到了什么、要做什么
- 整理区：由自己或 AI 在当天末尾补充复盘、观察、跨库整理和后续行动

这种结构的好处是：原始记录不会被整理笔记覆盖，整理内容也不会混进当时的真实感受里。

这个系统还保留了一个很有趣的小模块：占卜记录。它不是用来替代判断，而是把“我问了什么、抽到了什么、当下直觉是什么、第二天现实如何回应”记录下来。久了以后，你会看到自己的提问方式、担心模式和直觉变化。

占卜也可以用于年度计划。它负责提供问题和方向，帮助你从迷茫里看见主题、阻碍和资源；AI 负责把这些方向整理成大目标，再拆成可执行任务；月度任务池负责把任务放进具体月份，月末复盘再根据真实进度调整下一步。

## 插件要求

基础版不需要安装第三方社区插件。下载后用 Obsidian 打开 `vault-template/` 就能开始写。

模板库里已经配置了 Obsidian 核心功能：

- Daily notes
- Templates

如果你想做进阶查询、任务汇总或自动化，可以按需安装社区插件。见 [插件安装说明](docs/plugins.md)。

## 使用方式

### 直接打开模板库

1. 在 GitHub 页面点击绿色 `Code` 按钮。
2. 点击 `Download ZIP` 下载本仓库。
3. 解压 ZIP。
4. 用 Obsidian 打开 `vault-template/` 文件夹。
5. 打开 `00-首页.md`，从首页进入日常总览和模板区。
6. 每天用 `90-模板/日记模板.md` 新建一页。

### 如果你已经拿到了 ZIP

1. 解压 ZIP。
2. 用 Obsidian 打开 `vault-template/` 文件夹。
3. 打开 `00-首页.md`，从首页进入日常总览和模板区。
4. 每天用 `90-模板/日记模板.md` 新建一页。

### 手动搬进已有 vault

1. 在 Obsidian 中打开你自己的 vault。
2. 按照 [系统结构说明](docs/system-overview.md) 建立目录。
3. 把 `templates/` 里的模板复制到你的模板目录。
4. 每天用日记模板新建一页。
5. 每周或每月把每日记录汇总到周记/月度复盘。
6. 如果使用 AI 整理，请把 AI 输出固定放在 `## Codex整理今日摘要` 之下。

## 隐私原则

公开发布个人手帐系统时，最重要的是只公开“系统”，不要公开“人生现场”。发布前请先完成 [发布前隐私检查清单](docs/publish-safety-checklist.md)。

建议公开：

- 目录结构
- 模板
- 脱敏示例
- 自动化思路
- 使用说明

不建议公开：

- 真实日记
- 家庭成员、住址、行程细节
- 账单、快递、邮件、电话、账号信息
- 图片、视频、附件
- 同步脚本里的 token、cookie、密钥、缓存文件

## 自动化

这个系统可以和 Microsoft To Do、邮件同步、AI 摘要等流程连接。公开仓库里只建议放说明和伪代码，不建议放本机真实脚本或任何凭据。见 [自动化说明](automation/README.md)。
