# 个人日记手帐系统

这是一个基于 Obsidian 的个人日记、家务、财务、计划与复盘系统模板。它不是单纯的日记本，而是把每日记录、待办推进、消费记录、旅行复盘、阶段计划和 AI 辅助整理放在同一套可持续维护的结构里。

这个公开版本只保留方法、结构、模板和脱敏示例，不包含真实日记正文、家庭信息、地点、账号、附件或自动化密钥。

## 适合谁

- 想把日记写成可复盘系统，而不是零散流水账的人
- 需要同时管理生活、家庭事务、旅行、采购、工作记录和长期计划的人
- 已经在用 Obsidian，希望让每日笔记和待办系统连接起来的人
- 想让 AI 帮忙整理每日摘要，但又希望人工记录和 AI 观察分开的用户

## 核心设计

每日页分为两层：

- 主记录区：今天发生了什么、花了什么、想到了什么、要做什么
- 整理区：由自己或 AI 在当天末尾补充复盘、观察、跨库整理和后续行动

这种结构的好处是：原始记录不会被整理笔记覆盖，整理内容也不会混进当时的真实感受里。

## 使用方式

1. 在 Obsidian 中新建一个 vault。
2. 按照 [系统结构说明](docs/system-overview.md) 建立目录。
3. 把 `templates/` 里的模板复制到你的模板目录。
4. 每天用日记模板新建一页。
5. 每周或每月把每日记录汇总到周记/月度复盘。
6. 如果使用 AI 整理，请把 AI 输出固定放在 `## Codex整理今日摘要` 之下。

## 隐私原则

公开发布个人手帐系统时，最重要的是只公开“系统”，不要公开“人生现场”。发布前请先完成 [发布前隐私检查清单](docs/publish-safety-checklist.md)。

建议公开：

- 目录结构
- 模板
- 脱敏示例
- 自动化思路
- 使用说明

不建议公开：

- 真实日记
- 家庭成员、住址、行程细节
- 账单、快递、邮件、电话、账号信息
- 图片、视频、附件
- 同步脚本里的 token、cookie、密钥、缓存文件

## 自动化

这个系统可以和 Microsoft To Do、邮件同步、AI 摘要等流程连接。公开仓库里只建议放说明和伪代码，不建议放本机真实脚本或任何凭据。见 [自动化说明](automation/README.md)。
