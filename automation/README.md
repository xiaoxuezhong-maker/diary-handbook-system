# 自动化说明

这个系统可以连接自动化，但公开仓库里建议只放说明，不放真实脚本。

## 可以自动化的部分

- 从日记中的 `- [ ]` 待办同步到 Microsoft To Do
- 从邮件中提取需要处理的事项
- 每晚根据当天日记生成整理摘要
- 把旅行、工作、资料类记录归档到对应主题页
- 根据消费记录生成月度财务回顾

## 不建议公开的内容

- refresh token
- cookie
- API key
- 本机绝对路径
- 账号 ID
- 邮箱地址
- 原始同步日志
- 含真实事项的任务缓存

## 推荐公开方式

如果要公开自动化部分，建议写成：

- 工作流说明
- 伪代码
- 环境变量示例
- 不含个人路径的脚本骨架

示例：

```powershell
# 伪代码：从日记中读取待办并同步到外部任务系统
# 1. 读取指定日期范围的 Markdown 文件
# 2. 提取未完成的 "- [ ]" 行
# 3. 对比外部任务系统中已有任务
# 4. 创建、更新或标记完成
# 5. 输出同步摘要
```

## 同步边界

建议把自动化和日记编辑分开：

- 同步脚本只同步待办
- 日记正文由自己或确认后的 AI 编辑
- 同步失败时只报告错误，不自动改写日记
