# 每日明日运势卡片工作流

这个工作流用于每天抽取“明日运势卡片”，并在日记中形成固定循环：

- 今天复盘昨天的占卜信息
- 今天抽取明天的运势卡片
- 用固定牌阵和固定解读方向让 AI 解读
- 只输入每日变化的牌面信息，避免每天重复写问题
- 把解读转成合理预期和正念练习

## 核心思路

固定的不是每天的问题，而是牌阵和解读方向。

每天只需要输入：

- 日期
- 抽到的牌/符号
- 直觉关键词
- 当天现实反馈

AI 按固定结构输出：

- 明日主题
- 可能出现的情绪
- 适合推进的事
- 需要放轻的事
- 正念提醒
- 具体行动建议

## 固定牌阵示例

可以从简单三位开始：

```text
1. 明日主题：这张牌提示明天的整体气氛
2. 需要注意：这张牌提示容易卡住或过度反应的地方
3. 正念练习：这张牌提示明天可以如何安放自己
```

这只是示例。你可以让 AI 根据你的习惯生成更适合自己的固定牌阵。

## 生成固定牌阵的提示词

```text
请帮我设计一个适合每日明日运势记录的固定牌阵。

我的使用习惯：
- 我每天会抽取明日运势卡片
- 我希望每天只输入牌面信息，不重复写问题
- 我会在第二天日记里复盘前一天的占卜
- 我希望它帮助我合理预期明日事件，同时结合正念练习

要求：
- 牌阵不要太复杂，适合每天使用
- 每个位置都要有固定解读方向
- 解读要偏现实、温和、行动导向
- 不要给绝对预测
- 输出一个可复制到日记模板里的格式
```

## 每日 AI 解读提示词

```text
请按我固定的每日明日运势牌阵，解读下面的牌面信息。

固定解读方向：
1. 明日主题
2. 需要注意
3. 正念练习
4. 合理预期
5. 明日一个小行动

今日输入：
- 日期：
- 抽到/看到：
- 我的第一直觉：
- 现实背景：

请注意：
- 不要把解读写成绝对预测
- 请帮我建立合理预期，而不是制造焦虑
- 请把牌义和正念练习结合起来
- 最后给一个明天可以执行的小提醒
```

## 第二天复盘提示词

```text
请帮我复盘昨天的明日运势卡片。

昨天的记录：
- 抽到/看到：
- AI 当时的解读：
- 我当时的第一直觉：

今天现实发生了什么：
- 

请输出：
1. 哪些地方和现实有呼应
2. 哪些地方只是我当时的情绪投射
3. 我对这张牌/符号的新理解
4. 这次复盘对我明天的正念练习有什么帮助
```

## 日记中的位置

建议放在每日页：

```markdown
## 占卜记录

### 昨日占卜复盘

### 明日运势卡片
```

AI 整理后的内容可以放进：

```markdown
## Codex整理今日摘要

### 前日占卜复盘

### 明日占卜解读
```
