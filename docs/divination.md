# 占卜记录说明

占卜记录是这个日记系统里比较有趣的一部分。

它不是为了预测未来，也不是为了替代自己的判断。它更像一个提问和复盘工具：把当下的疑问、抽到的牌或符号、第一直觉、现实观察和第二天复盘放在同一处。

## 为什么要记录

很多时候，占卜真正有价值的地方不是答案，而是它让你看见自己正在问什么。

比如：

- 你反复担心什么
- 你在哪些事情上需要外部确认
- 你对某个选择的第一反应是什么
- 第二天回看时，现实和当时的直觉有什么差异

这些内容放进日记里，会让它成为一种长期观察自己的方法。

## 每日页里的结构

建议在每日笔记中保留：

```markdown
## 占卜记录

- 提问：
- 使用方式：
- 抽到/看到：
- 第一直觉：
- 现实观察：
- 明日复盘：
```

这些字段可以用于塔罗、雷诺曼、神谕卡、随机词、梦境符号，或者任何你自己的直觉练习。

## 复盘方式

第二天或几天后，在 `## Codex整理今日摘要` 下使用：

```markdown
### 前日占卜复盘

- 昨天的问题：
- 当时的直觉：
- 今天现实发生了什么：
- 哪些部分有帮助：
- 哪些部分只是情绪投射：
```

复盘时不要强行把现实套进牌义里。重点是观察：

- 它有没有帮你换一个角度
- 它有没有暴露真实担心
- 它有没有提醒一个具体行动
- 它有没有被事实推翻

## 占卜解读区

如果当天想进一步解释，可以放在：

```markdown
### 占卜解读
```

建议写成温和的可能性，而不是确定断言。

可以使用这些句式：

- 这可能在提醒我：
- 我现在更在意的是：
- 如果把它当成建议，可以转成：
- 需要等现实验证的部分是：

## 安全边界

建议不要用占卜替代：

- 医疗决定
- 法律决定
- 财务投资决定
- 重大关系决定
- 任何需要现实证据和专业意见的判断

更稳妥的做法是：占卜负责提出角度，现实负责验证，行动由自己决定。

## 用在年度计划里

占卜也可以用于年度目标设计。

推荐流程：

1. 先让 GPT 设计一套年度占卜问题
2. 用塔罗、雷诺曼或其他工具逐题记录
3. 让 GPT 从记录里整理年度大目标
4. 让 GPT 把大目标拆成可执行任务
5. 再记录每个月的月度关键词或月度运势
6. 按月份把任务分配进去
7. 最后人工检查是否有遗漏、过载或长期任务没有持续安排

完整流程见 [年度目标占卜工作流](annual-planning-with-divination.md)。

## 用在每日明日运势里

也可以每天抽一组“明日运势卡片”。

建议固定牌阵和解读方向，这样每天只需要输入牌面信息，不必重复写问题。第二天再在日记里复盘它和现实的关系。

这个循环有两个作用：

- 帮助你理解牌义和自己的直觉
- 帮助你对明天建立合理预期，并结合正念练习安放情绪

完整流程见 [每日明日运势卡片工作流](daily-divination-card.md)。
