# 月末 AI 复盘工作流

这个工作流用于每个月结束后，让 AI 帮你整理日记、核对任务完成度，并对下个月的任务池做反馈和调整。

## 输入材料

建议提供给 AI：

- 本月所有日记
- 本月任务池
- 年度目标或本月目标
- 本月占卜/关键词记录
- 已完成任务
- 未完成任务
- 你对本月的主观感受

## 提示词

```text
请根据我这个月的日记和任务池，帮我做一次月末复盘。

请注意：
- 不要批评我，也不要只按完成率评价
- 请区分“没做”“做了但没写”“任务太大”“时机不对”“目标已不重要”
- 请把真实进展和情绪感受分开
- 请检查任务池里的任务完成度
- 请指出哪些任务应该继续、缩小、延期、删除或转成长期任务
- 请根据本月实际情况，给下个月任务池提出调整建议

请输出：
1. 本月一句话总结
2. 本月真实进展
3. 任务完成度核对
4. 未完成任务原因分析
5. 长期任务推进情况
6. 本月占卜/关键词是否有现实反馈
7. 下个月任务池建议
8. 需要我手动确认的事项
```

## 任务完成度核对

建议把任务分成：

- 已完成
- 部分完成
- 做了但没有记录
- 没做但仍然重要
- 没做且应删除
- 需要缩小
- 需要延期
- 转为长期任务

这样比单纯“完成/未完成”更符合真实生活。

## 下个月任务池调整

AI 可以给建议，但最后要人工确认。

下个月任务池建议包含：

- 必做任务
- 推进任务
- 维护任务
- 长期任务小版本
- 暂缓任务
- 删除任务

## 人工确认清单

- [ ] AI 有没有误判“没写”为“没做”
- [ ] 未完成任务是否真的还重要
- [ ] 下个月任务数量是否可承受
- [ ] 长期任务是否每个月都有小版本
- [ ] 占卜/关键词有没有被过度解释
- [ ] 是否保留了现实生活的弹性
