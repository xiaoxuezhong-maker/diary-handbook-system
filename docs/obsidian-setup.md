# Obsidian 设置建议

## 基础插件

建议先用 Obsidian 的核心功能完成系统，不要一开始装太多插件。

可用核心功能：

- 模板
- 每日笔记
- 文件恢复
- 反向链接
- 标签

## 模板路径

建议把模板统一放在：

```text
90-模板/
```

在 Obsidian 设置中把模板文件夹指向这个目录。

## 每日笔记路径

建议每日笔记放在：

```text
01-日常手账/05 Diary/
```

文件名格式：

```text
YYYY-MM-DD
```

## 待办写法

可执行待办统一使用：

```markdown
- [ ] 明确的下一步动作
```

已经完成：

```markdown
- [x] 已完成的动作
```

避免把愿望、感受、提醒和行动混在一起。比如：

- `想变得更有规律` 适合放在感悟里
- `晚上 22:30 前准备明天衣服` 才适合放进待办

## AI 整理建议

如果用 AI 辅助总结，建议保留边界：

- 原始记录区由自己写
- AI 整理区放在 `## Codex整理今日摘要`
- AI 生成的建议先作为建议，不自动变成待办
- 确认要做的事再写进 `## 待办事项`
