# 插件安装说明

这个公开模板库的基础记录功能不依赖第三方社区插件。

但“待办事项整理”要分情况：

- 只在当天日记里写 `- [ ]` 并手动勾选：不需要社区插件
- 月末让 AI 根据日记和任务池做复盘：不强制需要社区插件
- 想自动汇总跨页面待办、筛选未完成任务、查看任务池完成度：建议安装 `Tasks` 或 `Dataview`

模板库里已经包含：

```text
01-日常手账/待办事项总览.md
```

这个页面提供 Tasks 和 Dataview 查询示例。安装插件后，它可以自动显示跨页面待办，但不会把待办从原始日记复制出来。

## 已包含的核心功能配置

`vault-template/.obsidian/` 里已经配置了 Obsidian 的核心功能：

- `Daily notes`：每日笔记
- `Templates`：模板

打开 `vault-template/` 后，Obsidian 会识别这些配置。你仍然可以在 Obsidian 设置里按自己的习惯调整。

## 不包含什么

这个仓库不打包社区插件本体，也不包含私人自动化脚本。

原因是：

- 社区插件应从 Obsidian 内置插件市场安装，版本更安全
- 不同用户的插件需求不同
- 原始自动化脚本可能包含本机路径、账号缓存或隐私信息

## 可选社区插件

以下插件不是基础写作必需，但如果你想做自动化整理，会很有用。

### Calendar

适合想从日历视图打开每日笔记的人。

用途：

- 更方便地跳转日期
- 查看哪些日期已经写过

### Periodic Notes

适合想管理周记、月记、季度复盘的人。

用途：

- 创建周记
- 创建月度复盘
- 配合每日笔记做周期回顾

### Dataview

适合想自动汇总任务、任务池、花费、标签或复盘条目的人。

用途：

- 汇总某个月的日记
- 查询未完成待办
- 汇总每个月的任务池
- 按年度目标查看关联任务
- 生成主题索引

当前公开模板已经在 `待办事项总览.md` 里提供了基础 Dataview 查询示例。更复杂的财务汇总、标签索引和年度目标查询，需要根据自己的记录格式继续添加。

### Tasks

适合想更精细地管理 Markdown 待办的人，尤其是跨页面任务整理。

用途：

- 按日期、标签、完成状态筛选待办
- 汇总跨页面任务
- 检查某个月有哪些未完成任务
- 配合月末 AI 复盘准备任务清单

如果你最关心“待办事项整理”，优先安装 Tasks。

## 待办事项总览怎么工作

推荐方式是“查询显示”，不是“复制搬运”。

原因是同一个待办如果既存在日记里，又被复制到待办事项笔记里，完成状态很容易不一致。用 Tasks 或 Dataview 查询时，原始待办仍然留在原来的日记或任务池里，总览页只负责显示。

如果你安装 Tasks，可以从这段开始：

```tasks
not done
path includes 01-日常手账
sort by path
sort by due
```

如果你安装 Dataview，可以从这段开始：

```dataview
TASK
FROM "01-日常手账"
WHERE !completed
SORT file.path ASC
```

### Templater

适合想写更复杂模板逻辑的人。

用途：

- 自动生成复杂日期
- 批量插入固定结构
- 编写更灵活的模板脚本

注意：当前模板使用 Obsidian 核心 Templates 的 `{{date}}`，不需要 Templater。

## 建议安装顺序

如果你是第一次使用，建议先不装社区插件。

推荐顺序：

1. 先用基础模板写 3-7 天
2. 如果需要日历视图，再装 Calendar
3. 如果需要跨页面整理待办，先装 Tasks
4. 如果需要自动汇总日记、任务池和索引，再装 Dataview
5. 如果需要周记/月记自动化，再装 Periodic Notes
6. 如果需要复杂模板，再装 Templater

## 安装方式

在 Obsidian 中打开：

```text
设置 -> 第三方插件 -> 关闭安全模式 -> 浏览
```

搜索插件名，点击安装并启用。
