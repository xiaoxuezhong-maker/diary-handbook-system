# 插件安装说明

这个公开模板库的基础功能不依赖第三方社区插件。

## 已包含的核心功能配置

`vault-template/.obsidian/` 里已经配置了 Obsidian 的核心功能：

- `Daily notes`：每日笔记
- `Templates`：模板

打开 `vault-template/` 后，Obsidian 会识别这些配置。你仍然可以在 Obsidian 设置里按自己的习惯调整。

## 不包含什么

这个仓库不打包社区插件本体，也不包含私人自动化脚本。

原因是：

- 社区插件应从 Obsidian 内置插件市场安装，版本更安全
- 不同用户的插件需求不同
- 原始自动化脚本可能包含本机路径、账号缓存或隐私信息

## 可选社区插件

以下插件不是必需，只适合进阶使用。

### Calendar

适合想从日历视图打开每日笔记的人。

用途：

- 更方便地跳转日期
- 查看哪些日期已经写过

### Periodic Notes

适合想管理周记、月记、季度复盘的人。

用途：

- 创建周记
- 创建月度复盘
- 配合每日笔记做周期回顾

### Dataview

适合想自动汇总任务、花费、标签或复盘条目的人。

用途：

- 汇总某个月的日记
- 查询未完成待办
- 生成主题索引

注意：当前公开模板没有内置 Dataview 查询，安装后需要自己添加查询语句。

### Tasks

适合想更精细地管理 Markdown 待办的人。

用途：

- 按日期、标签、完成状态筛选待办
- 汇总跨页面任务

### Templater

适合想写更复杂模板逻辑的人。

用途：

- 自动生成复杂日期
- 批量插入固定结构
- 编写更灵活的模板脚本

注意：当前模板使用 Obsidian 核心 Templates 的 `{{date}}`，不需要 Templater。

## 建议安装顺序

如果你是第一次使用，建议先不装社区插件。

推荐顺序：

1. 先用基础模板写 3-7 天
2. 如果需要日历视图，再装 Calendar
3. 如果需要周记/月记自动化，再装 Periodic Notes
4. 如果需要自动汇总，再装 Dataview 或 Tasks
5. 如果需要复杂模板，再装 Templater

## 安装方式

在 Obsidian 中打开：

```text
设置 -> 第三方插件 -> 关闭安全模式 -> 浏览
```

搜索插件名，点击安装并启用。
