# 发布前隐私检查清单

把个人日记系统发布到 GitHub 前，建议先把仓库当成一个“公开样板间”，而不是“真实生活备份”。

## 必须删除

- 真实日记正文
- 家庭成员姓名、昵称、关系细节
- 住址、门牌、小区、公司、学校、常去地点
- 电话、邮箱、账号、订单号、快递单号
- 身份证、护照、银行卡、票据、医疗信息
- 图片、视频、录音、截图、附件
- token、cookie、API key、refresh token、`.env` 文件
- 自动化脚本的本机路径、账号路径和缓存文件

## 建议替换

- 真实姓名替换为 `家人A`、`朋友B`、`同事C`
- 真实地点替换为 `城市A`、`海边小镇`、`附近超市`
- 金额替换为区间，比如 `约 100 元`
- 行程替换为概括，比如 `一次三天旅行`
- 具体日期可以保留模板日期，也可以改为示例日期

## 可以公开

- 目录结构
- 标题层级
- 模板
- 脱敏示例
- 工作流说明
- 自动化设计思路
- 使用心得

## GitHub 设置建议

- 第一次发布建议先建私有仓库
- 确认没有隐私内容后再改公开
- 不要把真实 Obsidian vault 直接设为公开仓库
- 使用 `.gitignore` 屏蔽附件、缓存、工作区状态和密钥
- 正式公开前，用 GitHub 网页再快速检查一次文件列表
