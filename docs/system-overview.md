# 系统结构说明

这个系统的目标不是把所有事情记得更满，而是让生活记录能够被回看、整理和转化为下一步行动。

## 每日记录层

每日页是系统的入口，建议按日期命名：

```text
01-日常手账/05 Diary/YYYY-MM-DD.md
```

如果日记数量很多，可以按月份分文件夹：

```text
01-日常手账/05 Diary/2026-06/2026-06-04.md
```

每日页包含：

- `今日摘要`：当天发生的事，用简短自然语言记录
- `每日打卡`：习惯、健康、家务、学习、工作状态
- `花费记录`：当天支出、待入账项目、异常花费
- `占卜记录`：提问、抽牌或符号、第一直觉、现实观察和第二天复盘
- `感悟和心得`：不急着行动化的感受
- `待办事项`：真实待办，只放可执行项
- `Codex整理今日摘要`：后续整理、旁观者观察、跨库索引和行动建议

## 占卜记录层

占卜记录不是单独漂在外面的内容，而是每日页的一部分。

建议把它当成一个“直觉和现实互相校验”的小模块：

- 先记录问题，不急着找答案
- 写下抽到的牌、符号、关键词或画面
- 保留第一直觉，不马上修饰
- 第二天或几天后复盘现实发生了什么
- 把有用的提醒转成具体行动，把不准的部分留作情绪观察

这部分不要强行绑定某一种牌系。塔罗、雷诺曼、神谕卡、梦境符号、随机词或自己的直觉练习都可以使用同一套记录结构。

## 计划层

计划层用于把每日记录向上汇总。

```text
01-日常手账/
  01 年度计划/
  02 季度计划/
  03 月度计划/
```

建议把计划写成弹性的方向和次数池，而不是每天必须完成的硬性清单。比如“本月整理素材 10 次”通常比“每天整理素材”更适合真实生活。

年度计划可以使用“占卜问题 + GPT 整理 + 任务拆解 + 月度任务池”的流程。这个流程特别适合对年度目标和任务拆解感到头疼的人：占卜负责提供方向，AI 负责结构化拆解，月度任务池负责落地执行。

- 先根据个人状态生成年度问题组
- 用塔罗、雷诺曼或其他直觉工具回答
- 让 GPT 整理年度大目标
- 让 GPT 拆成任务
- 用月度关键词或月度运势建立每月任务池
- 手动检查长期任务是否每个月都有小版本

每个月结束后，再让 AI 根据当月日记做月末复盘：

- 总结当月真实进度
- 核对任务池完成度
- 区分“没做”“做了但没写”“任务太大”“时机不对”
- 检查长期任务是否持续推进
- 对下个月任务池给出调整建议

## 主题层

主题层用于承接反复出现的生活领域。

```text
02-家庭/
03-旅行/
04-资料/
05-衣橱管理/
06-工作/
```

主题笔记不要替代每日页。每日页记录当天现场，主题页沉淀长期模式、清单、规则和复盘。

## 模板层

模板层用于降低每日启动成本。

```text
90-模板/
```

建议至少保留：

- 日记模板
- 周记模板
- 月度复盘模板
- 旅行计划模板
- 旅行复盘模板
- 待办事项模板

## 归档层

归档层用于收纳已经完成、暂不活跃、或只作为历史资料保留的内容。

```text
99-归档/
```

归档不是删除。它的作用是让当前系统保持轻，同时保留可追溯性。

## AI 整理区

建议固定使用：

```markdown
## Codex整理今日摘要
```

这个栏目有三个原则：

- 不覆盖人工原始记录
- 不把建议混进真实待办区
- 只在确认后把建议转成 `- [ ]` 待办

常用小标题：

- `### 旁观者观察`
- `### 几个库的整理`
- `### 前日占卜复盘`
- `### 占卜解读`
- `### 待办事项`
