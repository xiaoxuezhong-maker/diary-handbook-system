# 年度目标占卜工作流

这个工作流用于在迷茫时设计年度目标。

## 流程

1. 让 GPT 根据个人情况生成年度占卜问题
2. 用塔罗、雷诺曼或其他直觉工具逐题记录
3. 让 GPT 从记录里整理年度大目标
4. 让 GPT 把大目标拆成可执行任务
5. 抽取或记录每个月的月度关键词
6. 按月份把任务分配进去
7. 手动检查是否有遗漏、过载和长期任务

## 年度占卜问题生成提示词

```text
请帮我设计一套适合我的年度目标规划占卜问题。

我的背景：
- 我现在最迷茫的是：
- 我今年最想改善的领域：
- 我不想触碰或不适合用占卜判断的领域：
- 我使用的工具是：塔罗/雷诺曼/神谕卡/随机词/其他
- 我希望问题风格是：温和/直接/行动导向/疗愈导向/现实规划导向

要求：
- 不要替我做决定
- 问题要帮助我看见目标、阻碍、资源和行动
- 请按领域分组，而不是给我一个固定牌阵
- 每个问题后面写一句：这个问题想帮助我看见什么
- 最后给我一个适合记录答案的表格
```

## 任务拆解提示词

```text
请把这些年度大目标拆成可执行任务。

要求：
- 每个任务都要能被完成或检查
- 避免“变得更好”这种抽象表达
- 区分一次性任务、重复任务、长期任务和等待条件成熟的任务
- 给每个任务标注建议月份、依赖条件和最小版本
```

## 检查清单

- [ ] 每个年度大目标都有对应任务
- [ ] 每个任务都分配到月份
- [ ] 长期任务每个月都有小版本
- [ ] 每个月都有任务池
- [ ] 没有某个月明显过载
- [ ] 没有把占卜判断直接当成事实
- [ ] 已经手动调整到现实可执行

## 月末循环

每个月结束后，让 AI 整理当月日记和任务池：

- 总结当月真实进度
- 核对任务完成度
- 区分没做、做了但没写、任务太大、时机不对
- 给下个月任务池提出调整建议
