# 每日明日运势卡片工作流

这个工作流用于每天抽取“明日运势卡片”。

## 固定牌阵

可以先用简单结构：

1. 明日主题
2. 需要注意
3. 正念练习

也可以让 AI 根据你的习惯生成更适合自己的固定牌阵。

## 生成固定牌阵提示词

```text
请帮我设计一个适合每日明日运势记录的固定牌阵。

我的使用习惯：
- 我每天会抽取明日运势卡片
- 我希望每天只输入牌面信息，不重复写问题
- 我会在第二天日记里复盘前一天的占卜
- 我希望它帮助我合理预期明日事件，同时结合正念练习

要求：
- 牌阵不要太复杂，适合每天使用
- 每个位置都要有固定解读方向
- 解读要偏现实、温和、行动导向
- 不要给绝对预测
- 输出一个可复制到日记模板里的格式
```

## 每日解读提示词

```text
请按我固定的每日明日运势牌阵，解读下面的牌面信息。

固定解读方向：
1. 明日主题
2. 需要注意
3. 正念练习
4. 合理预期
5. 明日一个小行动

今日输入：
- 日期：
- 抽到/看到：
- 我的第一直觉：
- 现实背景：

请注意：
- 不要把解读写成绝对预测
- 请帮我建立合理预期，而不是制造焦虑
- 请把牌义和正念练习结合起来
- 最后给一个明天可以执行的小提醒
```
